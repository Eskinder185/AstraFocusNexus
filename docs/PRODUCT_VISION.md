# AstraFocus — Product Vision

> **Plan with clarity. Focus with intention. Make meaningful progress.**

## The problem

People who juggle classes, code, clients and goals run their lives across five tools: a task app, a calendar, a notes app, a timer, and a spreadsheet of goals. The cost isn't the subscriptions. It's the gaps between them:

1. Tasks are scattered, so nothing feels under control.
2. Goals never become scheduled action.
3. Workload is underestimated, so days are over-committed.
4. Focus is lost to context switching.
5. There's no honest answer to "did today move my goals forward?"

## The promise

One calm workspace that runs the whole cycle:

```
CAPTURE → ORGANISE → PRIORITISE → SCHEDULE → FOCUS → COMPLETE → REFLECT → IMPROVE
```

Every feature must strengthen a step in that loop. If it doesn't, it doesn't ship.

## Who it's for (in order)

1. **Students**: assignments, exams, certifications, personal goals. *Initial focus.*
2. **Developers and technical professionals**: projects, learning, deep work.
3. **Freelancers**: client deadlines, time awareness.
4. **Busy professionals and creators**: tasks + calendar + goals in one place.

Teams come later, on an architecture designed for them, but never at the expense of a great personal product.

## Principles

- **Truthful by default.** No fake stats, no placeholder integrations, no "coming soon" buttons that look real. Insights appear only when data supports them.
- **Fast capture, slow thinking.** Capturing a task takes one keystroke. Deciding what matters gets deliberate tools: the matrix, goals, weekly review.
- **Focus is the product.** The timer is a first-class surface, not a widget.
- **Keyboard-first, touch-excellent.** ⌘K and single-key shortcuts on desktop; a purpose-built bottom bar on mobile.
- **Calm, not clinical.** Supportive copy. No guilt streaks, no medical claims.
- **Private by default.** Wellness data never leaves the device unless the user explicitly chooses.
- **Your data is yours.** Export is always one click.

## Design language

An original identity built from typography, spacing and restraint rather than decoration:

- **Palette:** deep ink surfaces, an "orbit" violet accent, and a warm "star" gold reserved for moments of progress (the running timer, the item in focus, the top priority).
- **Mark:** an open orbit around a star. The gap in the orbit is the starting point: the next step.
- **Type:** Inter Variable at a dense 14 px UI base, tabular numerals for all time and counts.
- **Motion:** short, purposeful transitions that explain state changes; fully disabled under `prefers-reduced-motion`.

## What "premium" means here

People pay for software that saves them time and makes them feel in control. For AstraFocus that is:

1. A Focus Studio that makes people *want* to start a session.
2. Planning that turns a goal into calendar time (Phase 3).
3. Sync they never think about (Phase 6).
4. A weekly review that tells the truth about where time went (Phase 7).

## Monetisation hypothesis (to validate, not to build yet)

| Tier | Hypothesis | Must remain true |
|---|---|---|
| Free | Tasks, matrix, goals, focus timer, local data | Genuinely useful forever |
| Pro (~$8/mo annual) | Sync, calendar + integrations, planning engine, analytics, premium focus themes, rich notes | Only features that work today |
| Team (~$12/user/mo annual) | Shared workspaces, assignments, team analytics | Only after isolation tests pass |

Prices are hypotheses. No billing ships without explicit authorisation and working entitlements enforced server-side.
